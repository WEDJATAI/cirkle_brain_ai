   201→   201→# 4. WEDJAT BRAIN CONSTITUTION
   202→   202→
   203→   203→The following rules are mandatory and override convenience.
   204→   204→
   205→   205→## Rule 1 — No false intelligence claims
   206→   206→
   207→   207→Do not claim that Wedjat trained its underlying model when the system merely:
   208→   208→
   209→   209→* stored memory
   210→   210→* added documents
   211→   211→* updated prompts
   212→   212→* changed retrieval
   213→   213→* changed routing
   214→   214→* changed tool policies
   215→   215→
   216→   216→Use accurate terminology.
   217→   217→
   218→   218→---
   219→   219→
   220→   220→## Rule 2 — Model output is not automatically truth
   221→   221→
   222→   222→Never automatically convert:
   223→   223→
   224→   224→```text
   225→   225→LLM output
   226→   226→```
   227→   227→
   228→   228→into:
   229→   229→
   230→   230→```text
   231→   231→verified knowledge
   232→   232→```
   233→   233→
   234→   234→unless independent evidence or an explicit validated workflow justifies doing so.
   235→   235→
   236→   236→---
   237→   237→
   238→   238→## Rule 3 — Authorization is outside the model
   239→   239→
   240→   240→The model may request an action.
   241→   241→
   242→   242→The policy/authorization layer decides whether that action is permitted.
   243→   243→
   244→   244→---
   245→   245→
   246→   246→## Rule 4 — Retrieved content is untrusted
   247→   247→
   248→   248→Documents, websites, emails, tool results, user-provided text, and external data may contain malicious instructions.
   249→   249→
   250→   250→They must never be treated as system-level instructions.
   251→   251→
   252→   252→---
   253→   253→
   254→   254→## Rule 5 — Tenant isolation is mandatory
   255→   255→
   256→   256→The Brain must never leak:
   257→   257→
   258→   258→* memories
   259→   259→* documents
   260→   260→* knowledge
   261→   261→* conversation information
   262→   262→* tools
   263→   263→* data
   264→   264→* credentials
   265→   265→* hidden metadata
   266→   266→
   267→   267→between unauthorized tenants, users, applications, or organizations.
   268→   268→
   269→   269→---
   270→   270→
   271→   271→## Rule 6 — Side effects require explicit authorization
   272→   272→
   273→   273→A model recommendation is not execution.
   274→   274→
   275→   275→Distinguish:
   276→   276→
   277→   277→```text
   278→   278→recommendation
   279→   279→draft
   280→   280→simulation
   281→   281→requested action
   282→   282→authorized action
   283→   283→executed action
   284→   284→verified result
   285→   285→```
   286→   286→
   287→   287→---
   288→   288→
   289→   289→## Rule 7 — Important knowledge has provenance
   290→   290→
   291→   291→The Brain must be able to determine:
   292→   292→
   293→   293→```text
   294→   294→where did this information come from?
   295→   295→when was it obtained?
   296→   296→what evidence supports it?
   297→   297→what version was used?
   298→   298→is it still valid?
   299→   299→does conflicting evidence exist?
   300→   300→```
   301→   301→
   302→   302→---
   303→   303→
   304→   304→## Rule 8 — Knowledge is temporal
   305→   305→
   306→   306→The Brain must distinguish:
   307→   307→
   308→   308→```text
   309→   309→current
   310→   310→historical
   311→   311→future/scheduled
   312→   312→expired
   313→   313→unknown
   314→   314→conflicted
   315→   315→```
   316→   316→
   317→   317→---
   318→   318→
   319→   319→## Rule 9 — Learning is controlled
   320→   320→
   321→   321→Production activity may generate:
   322→   322→
   323→   323→```text
   324→   324→learning candidates
   325→   325→```
